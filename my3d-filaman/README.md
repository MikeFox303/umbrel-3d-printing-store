# FilaMan для Umbrel

Это неофициальный Community App package. FilaMan разработан Fire-Devils; русская локализация основана на официальном open-source проекте.

Перед установкой замените placeholder digest в `docker-compose.yml` на digest опубликованного multi-architecture образа. Для Raspberry Pi 5 образ обязан содержать `linux/arm64`.
